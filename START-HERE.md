#### Windows
```batch

```
*Doble click y listo. Se abrirán 2 ventanas automáticamente.*


##  LO QUE OBTIENES

### Al Ejecutar el Script de Inicio

1. **Servidor Django funcionando**
   - Puerto: 8000
   - Auto-reload activado
   - Navegador abre solo

2. **Monitor de Logs (Ventana separada)**
   - Actualiza cada 30s
   - Muestra errores nuevos
   - Con colores ()

3. **Logs Automáticos**
   - 4 archivos: general, errors, api, auth
   - Se generan solos
   - Rotan automáticamente
