  2️⃣  Haz clic en "Explorar Recorridos"

┌───────────────────────────────────────────────────────────────────────┐
│  🔧 AGREGAR MÁS RECORRIDOS                                             │
└───────────────────────────────────────────────────────────────────────┘

  Para agregar fotos a otros recorridos:

  1. Coloca las fotos en:
     proyecto/imagenes/mapa/[nombre-recorrido]/

  2. Edita: proyecto/src/frontend/streetview/streetview.js

  3. Busca el recorrido (ej: 'biblioteca')

  4. Cambia: disponible: false → disponible: true

  5. Agrega las imágenes:
     imagenes: [
       {
         url: '/imagenes/mapa/biblioteca/img1.jpeg',
         titulo: 'Entrada Biblioteca',
         descripcion: 'Vista de la entrada'
       },
       // ... más imágenes
     ]

  6. Guarda y recarga la página

┌───────────────────────────────────────────────────────────────────────┐
│  ❓ PROBLEMAS COMUNES                                                  │
└───────────────────────────────────────────────────────────────────────┘

  ❌ Las imágenes no cargan:
     → Verifica que existen en proyecto/imagenes/mapa/casino/
     → Revisa la consola (F12) para errores 404

  ❌ El visor no se abre:
     → Abre consola (F12) y busca errores JavaScript
     → Limpia caché (Ctrl+Shift+R)

  ❌ Los swipes no funcionan:
     → Asegúrate de estar en modo responsive (mobile)
     → Swipe debe ser de mínimo 50 píxeles

  ❌ Las cards no se ven bien:
     → Limpia caché del navegador
     → Verifica que streetview.css se cargó
