# Notas de Versiones - StudentsPoint

Esta carpeta contiene las notas de versión (release notes) de StudentsPoint, documentando cambios, mejoras y correcciones en cada versión del proyecto.

## Versiones Disponibles

- [v5.1.0](RELEASE_NOTES_v5.1.0.md) - Sistema de reportes con fotos, mejoras en encuestas y foros

## Formato de Notas de Versión

Cada archivo de release notes incluye:
- **Nuevas funcionalidades**: Características agregadas
- **Mejoras**: Optimizaciones y refinamientos
- **Correcciones**: Bugs solucionados
- **Cambios breaking**: Cambios que requieren atención especial
- **Notas de migración**: Pasos necesarios para actualizar

## Semantic Versioning

El proyecto sigue [Semantic Versioning](https://semver.org/):
- **MAJOR** (X.0.0): Cambios incompatibles en la API
- **MINOR** (0.X.0): Nueva funcionalidad compatible con versiones anteriores
- **PATCH** (0.0.X): Correcciones de bugs compatibles
